# BookShelf — Frontend

Modern online bookstore frontend. This first iteration implements the
**Authentication layout** and the **Login page**.

## Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router v6
- Axios

## Getting started
```bash
npm install
cp .env.example .env      # set VITE_API_BASE_URL to your API URL
npm run dev
